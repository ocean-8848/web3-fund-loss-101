## 场景

- scope 库里有什么（5 句）：213 点阵按日期出现 → 首末两点 → 按 EX/W 着色 → 一行拆成字段卡 → 来源核对条。
- dist 分布（6 句）：同一组点在年份 / 类型 / 金额档三种单位图之间重排 → 合计条 + Binance 段 → 手法条形图，件数→金额变宽并换名次。
- evid 证据、层数与归因（6 句）：同一点阵按证据标签着色归队 → 标出含 C → 换成层数空值 → 换成归因未知 → 三条朝鲜相关措辞放在“证据强→弱”轴上。
- use 怎么查（5 句）：筛选栏 → 选手法、金额 → 213 行收成 7 行 + 合计 → 独立章链接 → 口径条。
