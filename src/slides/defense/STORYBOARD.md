## 场景

1. goal（4 句）攻击者 → 资产的红箭头（第 1–2 部分）→ 三道独立关卡，一道失陷、下一道拦住 → 下方时间线“转出 → 发现 → 止损 → 追回”，括出“分钟级” → 收成 D01–D05 五章路径，括号分防御 / 应急响应。
2. three（7 句）三栏三个问题。钱在哪：热 / 温 / 冷余额柱 + 上限虚线 + 超额归集箭头 → 热钱包冲破上限变红。谁能动：钥匙 / 系统 / 角色汇到“签名” → 开发机从旁驱动签名。多久能停：转出 → 告警 → 停签两段“? 分钟” → 变红“数年 / 仍在流出”。
3. chain（8 句）六步攻击链；绿色反向箭头“越靠左越早切断”；D02 三组控制从下方挂上；D03 横贯全程、D04 / D05 从上方挂到链上执行与洗钱；底部“能挽回”楔形变窄；按原型 A / B·C 高亮各自主防线；最后只留策略层与 D04，入口打问号。
4. depth（9 句）一道墙被射穿 → 分裂成六层墙；红色射线逐层推进，已失守的墙变红，当前层高亮，下方面板换成该层“假设 / 控制 / 案例”；第六层在资金之后；最后高亮第 4、5 层，给出“链上转账不可撤销”。
5. matrix（5 句）12 × 32 点阵 → 绿点 → 覆盖条与按覆盖数排序，第一行框黄、次三行框蓝 → 三行不依赖入口的行变绿 → 局限说明。
6. roadmap（7 句）三级台阶（月 / 季度 / 年），每级点亮时列出交付物，验收徽章挂在台阶上方；最后交付物变暗，只留验收徽章和“没有验证记录 = 没做”。
