## 场景

1. **gap 代码与设计的落差**（6 句）：两套规则的矩形错位，落差区域变红 = 漏洞；私钥 / 用户两项“没有”；按年份柱状图 + 计数，≥ $10M 部分染红，突出 2025。K1 K2 K3
2. **families 六种形态，一个结果**（6 句）：中心“合约放款给不该得到的人”，六类形态逐个长出并连线。K5
3. **invariant 共同根因：不变量**（7 句）：四条公开函数路径通向合约资产，三条过检查、一条没检查（Euler donateToReserves），资产被掏空；源码 → Vyper 编译器 → 部署合约锁失效，损失条与归还比例。K6 K7 K8
4. **rounding 舍入与空池**（6 句）：同样的舍入误差在满池与空池中的占比；上线时间轴红色风险段；Balancer v2 池内 EXACT_OUT 舍入 → batchSwap 内 BPT 价格曲线下行；三枚审计章。K9 K10
5. **cetus Cetus：一处溢出检查**（5 句）：本类前四排名条；checked_shlw 上限被越过却没拦住；极少代币 → 池 → 巨额流动性 → 攻击者；验证者冻结部分（冰蓝）；去中心化争议。K11
6. **defense 防线在开发到监控**（7 句）：开发 / 审计 / 升级·上线 / 监控四个节点，逐个点亮，下方依次换成不变量测试、CI、主网分叉回放、种子流动性、告警与暂停时间轴。K4 K12–K15
