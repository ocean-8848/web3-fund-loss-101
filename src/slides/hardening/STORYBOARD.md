# D02 安全建设与加固（hardening）分镜

源稿：`src/handbook/data/defense.js` 中 `id:"hardening"` 一章（§1–§12）。7 个场景，40 页。
这一章是全书最长的一章（8 个控制族的做法表 + 多链速查 + 管理要求 + 上线清单），slides 只取每族最关键的 P0 做法，每条尽量讲“做什么 → 怎样验证”。

## 没上 slides 的点及理由

- §1 EDR 覆盖开发机、关闭 AirDrop 接收、陌生联系人换渠道核实、远程招聘核验、签名专用设备、专项培训：同一族里优先讲了两条 P0 入口控制，篇幅所限。
- §2 会话绑定设备、权限清单季度复核、离职当天回收：同上，只取 MFA 与 JIT 两条。
- §3 管理面与钱包网段隔离、AI 编码工具按用户隔离、构建产物签名、机密集中管理：只讲 CI/CD 一条。
- §4 依赖锁定与 `--ignore-scripts`、供应商年度评估、外包最小化访问（Coinbase）、域名与 DNS 防护：P1 项，篇幅所限。
- §5 地址生命周期（Active → Deprecated → Retired）：P1，与出账主线关系较远。
- §6 Safe Guard（含 Guardrail 白名单延迟）、密钥仪式与分片保管（CCSS 1.03）、Solana durable nonce 预签名：细节多、需要单独画面，留给读原文。
- §7 输入与账户校验（EVM / Solana / Move）、主网分叉回放、高危修复私有流程（≤ 72 小时）、审计 + 赏金 + 编译器：篇幅所限。
- §8 治理防闪电贷、下游资产隔离上限：P1，篇幅所限。
- §9 多链差异速查：是对照表，逐链展开会变成表格截图；旧 D01 的 `chains` 场景已退役，本章不做。
