## 场景

1. outcome（4 句）只知道结果：热钱包 → 外部地址，前面补一个“入口 ?”；再收成 5 行同构链路 + 括号“归为一类”。
2. count（4 句）53 点阵（按损失排序）→ 36 点变黄 → $20 亿计数 → CEX / 关联服务比例条。
3. chain（5 句）mermaid 链路逐格长出，多链小道上的资产流向最后一格。
4. why（4 句）平台公告 vs 研究判断 / 执法确认空槽 → 四个平台围着问号 → “热钱包”标签的来源。
5. cases（7 句）时间轴 2020/2023/2025，逐个展开 KuCoin、Poloniex、Phemex；Phemex 用 1 小时多链轨道和估算区间条。
6. levers（4 句）累计转出曲线：余额线下压 → 停签线左移，损失平台随之降低；最后给出公式、划掉“入口 ?”。
7. controls（6 句）冷钱包 → 热钱包 → 管道 → 外部地址，四个控制依次装上；最后 L4 滑块演示。
