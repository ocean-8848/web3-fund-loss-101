## 场景

1. **windows 时间窗口**（6 句）：四段时间轴，资金（黄点）每句往前走一段、身后的轨道变红；上方写攻击者在做什么，下方长出还能打的牌，资金走过的段落里那几张牌变灰，最后只剩执法扣押和法院命令；末句在下方挂上交警 / 收费站 / 长期侦查的比喻和“难点在拦住”。
2. **path 典型洗钱路径**（7 句）：被盗资产 → DEX → 跨链 / 混币 → 上千地址 → 场外出金，按句逐个长出；冻结窗口虚线、Bitget 20 分钟、THORChain 三案、上千地址点阵变灰（长期不动）、约 31.3 亿美元；末句点阵变绿：持续标记、协同拦截。
3. **cards 七种追回手段**（7 句）：固定骨架“谁发起 → 谁执行 → 效果”，每句一封请求信封从发起方飞向执行方，执行方描边按颜色语义变化；下方换上该手段的前提、怎样发起、案例，右上角是窗口。
4. **firsthour 第一个小时的追回清单**（6 句）：上方赛跑（攻击者换币 vs 冻结请求送出）；下方 T+10 分钟 / T+1 小时两段：地址清单（可冻结 / 不可冻结标签）→ 三路同步；报案卡片与五个附件；追踪图上的标记圈、公开地址；末句上方换成二次诈骗警示。
5. **bounty 谈判、赏金与边界**（5 句）：赏金 → 制裁名单核查闸 → 攻击者；受害合约向攻击者地址发链上消息（归还地址、赏金比例、截止时间）并公开；Safe Harbor 事前采用流程 → 白帽抢救，抢救金额条分成退回回收地址与赏金两段；Tornado Cash 制裁时间线。
6. **vasp 平台的闸门与收尾**（6 句）：多路资金汇入交易所前的筛查闸；充值比对风险地址库三类来源 → 暂停入账；冻结请求 15 分钟时限流程；VASP A → B 转账与信息同行、非托管钱包大额转入尽调；FATF 83% / 其中近一半条形；分开记账五行与“净损失：追查结束才能确定”。

合计 6 场景 / 37 句。
