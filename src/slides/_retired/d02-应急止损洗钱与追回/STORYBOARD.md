## 场景

1. **gate 提现网关与停签**（7 句）：10 分钟圆环 → 左侧五层堆叠 → 右侧“用户 → 网关 → 签名服务 → 链上”，攻击者从下方绕过网关直连签名，币继续流出，Bitget 2.4 亿 → 签名服务开关拨到停签、出链箭头打叉 → “告警 → 全链停签 < 5 分钟”进度条。
2. **onchain 链上暂停与外部协同**（7 句）：同一五层堆叠，逐层点亮第 3–5 层。协议合约外流 + 单小时流出条撞阈值 → 自动暂停、暂停权不设失效期；热钱包被链上清扫合约抽走，服务器关停也没用，演练清除 7702 委托后切断；攻击者地址 10 分钟内广播给三方，时间轴上标出 10–20 分钟换币窗口与“复盘完才通知 → 已错过”。
3. **path 典型洗钱路径**（8 句）：按 Mermaid 的节点逐个长出（蛇形排布），配冻结窗口虚线、Bitget 20 分钟、THORChain 不封锁地址与三案标签、上千地址散点变灰（长期不动）、Binance 约 31.3 亿美元。
4. **cards 追回手段与时间窗口**（8 句）：底部 7 张牌，每句抬起一张，中间面板显示该手段的案例 / 效果 / 争议，有窗口说法的（分钟级、充值时、可能跨越数年）挂在右上角。
5. **chase 追回像追一辆车**（5 句）：车沿路跑过交警、收费站、侦查三段，每段下面写对应手段；最后场景变暗，眼睛图标 + “难点不在看到，在拦住”。
