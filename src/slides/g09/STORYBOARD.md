## 场景

1. **seen 看到了，不等于确定**（6 句）：链上最新区块里的充值 → 交易所“已确定”；该区块被重组后变红消失；认错的资产也进了账；交易所外框变红（攻击对象），链标注“按共识规则运行”；一格一件的年份方块图，Bitcoin Gold 染红。K1–K3
2. **reorg 双花：私链重组**（5 句）：公开链区块中的充值 X → 交易所入账 → 兑换后提走给攻击者；从第 2 块分叉出更长的红色私链；公开链后两块淡出、私链上移替代，入账被划掉“充值消失”；交易所变红“亏损”。K4
3. **cost 确认数与算力成本**（5 句）：面积图 时长 × 价格 = 攻击成本，确认块增多、面积拉长；ETC 时间轴标 Gate.io 2019-01 与 OKEx 2020-08；OKEx 细节与 560 万美元；确认数提高到数千个的绿色长条。K5–K7
4. **credit 入账缺陷：认错资产**（7 句）：“51% 算力”被划掉；三条输入通道依次进入交易所入账系统：仿冒 APT（type 未校验）、未完成的充值（形成余额，CertiK 提款 / 白帽争议）、XRP 部分支付与 EOS hard_fail；底部 Flow：执行层漏洞 → 伪造资产 → 跨链转出 → 验证者暂停链。K8–K11
5. **defense 确认数、识别与对账**（5 句）：算力租价条变短、确认块变多；识别规则卡（代币名称不作依据，合约地址、事件签名打勾），同名假代币被弹回“必须不入账”；入账总额与链上余额两条等长，逐笔核对，时间轴每小时打勾。K12–K14
