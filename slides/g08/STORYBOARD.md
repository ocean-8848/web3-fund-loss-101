## 场景

1. **inputs 代码没错，输入被改**（5 句）：合约方框“按设计运行”，三条输入箭头变红；一笔交易虚线框内闪电贷条拉满；一格一件的年份方块图，≥ $10M 的染红。K1–K3
2. **price 价格操纵链路**（5 句）：资金 → 浅市场（价格曲线上冲）→ 预言机 → 抵押品估值条变长 → 借出真资产 → 攻击者，绕成一圈；最后标出四个案件名。K4 K5
3. **cases 三起价格案例**（6 句）：Cream 金库“捐赠”抬价 + 循环借出；Tectonic 价格柱暴涨、9 个市场被借空、区块回滚箭头与恢复金额、回滚伦理；Ostium 签名者失陷 → 虚构价格 → 开平仓。K6–K8
4. **gov 治理攻击：Beanstalk**（4 句）：闪电贷 → 治理代币 → 恶意提案 → 金库 → 攻击者；67% 投票权条；整段框进“同一笔交易”，emergencyCommit 执行。K9 K10
5. **assume 同一个假设**（5 句）：市场价格曲线偏离真实价值线；“代码漏洞 / 私钥泄露：没有”；损失柱顶到风险参数上限线；被操纵资产流入下游借贷协议形成坏账并传染，两个例子。K11–K13
6. **defense 风险参数与时间锁**（7 句）：深度 / 借款上限 / 拉盘成本三条对比；三个价格源 → TWAP + 中位数，现货 ×3 冲出阈值带 → 借款暂停；LRT / 桥接资产独立上限，脱锚 → 自动暂停；治理时间轴：快照在提案前、借来的代币不能投票、通过到执行 ≥ 24 小时。K14–K18

合计 6 场景 / 32 页。
